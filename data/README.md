# Bundled sample data

`telco_customer_churn.csv` is the IBM Telco Customer Churn sample CSV copied from IBM's public [telco-customer-churn-on-icp4d repository](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv). The repository describes a fictional provider and includes the dataset under its Apache 2.0 repository license; a copy of that license is included beside the CSV.

The file has 7,043 records and 21 columns. IBM describes it as a Q3 snapshot of a fictional California telco. The sample does not specify a forward prediction horizon or record retention interventions. Blank `TotalCharges` entries are retained in the source file and imputed within model training folds.
